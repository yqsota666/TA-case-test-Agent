# 账户 AI 额度

账户设置通过剩余额度进度条展示用量，隐藏 token 数字与调用明细。普通账户显示充足、较少或用尽状态，以及北京时间零点恢复提示；演示账户显示“无限额度”，满条仅表示不限每日总量，不冒充剩余百分比。处理中预留与未知消耗用简短状态说明。数据来自服务端账本，不用 localStorage 估计消耗。接口仍保留本人实际用量与最近50次明细供后续监控看板使用。

普通账户默认使用 MODEL_USER_DAILY_TOKENS（50万），account_model_quotas 可按 user_id 覆盖；未设置的账户沿用默认值。降低额度不会清零历史消耗，下一次预留立即采用新额度。用户只能查看自己的额度，无修改 API 或管理员界面；后续监控看板再接入可信配置权限。

演示身份由 account_demo_users 服务端标记决定，不依赖客户端名称、邮箱或请求字段。新演示账户只由启用的 demo 登录入口创建标记；普通注册不能占用保留演示邮箱。既有本地演示账户部署时需先核对身份再写标记，不自动把任意历史同名账户升级。

演示账户无限每日额度，实际消耗照常结算并展示，不计入普通账户、工作空间和全局的每日预算桶；每次调用的豁免身份另表固化，结算不依赖身份后续变化。业务准入、并发、速率、单次输入输出与操作调用上限仍生效，演示调用占用全局并发和速率。

028为独立新表迁移，不改旧账本。回滚代码保留表；回滚后普通预算约束重新生效，演示专用预算桶保留历史，不删除未知消耗。真实 MySQL 专项 CASE_ACCOUNT_QUOTA_MYSQL=1 覆盖独立账户配置、降额不清零、跨账户账本隔离、演示超过普通额度仍可调用及未知用量记录。使用独立合成数据库。
