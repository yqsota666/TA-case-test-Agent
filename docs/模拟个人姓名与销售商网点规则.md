# 模拟个人姓名与销售商级网点

2026-10-10用户明确指定当前平台后端硬规则。这是当前测试环境要求，不把它描述为所有中登系统的统一限制。

- 模拟个人客户使用正常三个汉字姓名，例如陈思远、林雨桐。禁止模拟客户、销售商名称、代码、斜杠等标签。机构名称不套用个人三字限制。
- 01/03的DistributorCode读取实际选定通道；BranchCode等于该销售商代码，保留前导零。227→227、305→305、926→926、005→005，禁止追加001等后缀。此规则不改变TA代码、基金代码、交易账号或证件号。
- 当前同通道目标账户的TargetDistributorCode与TargetBranchCode也由所选通道填充。未来跨通道转托管需真实目标通道引用，不能靠修改网点伪造另一销售商。
- X1/X3从01开户记录复制姓名及机构/网点字段，因此同步遵守同一规则。协议编码和ZIP索引顺序继续由原有文件构造器处理。

模型产生不合规个人标签时，后端在准备方案展示和确认前生成正常三字姓名，保留已有合规姓名；人工编辑不合规姓名返回明确错误。最终01编译及申请入库再次校验，不能通过直接调用申请接口绕过。旧草稿账户中的网点后缀不再决定发文值，申请入库按所选通道核对网点，仍核对客户类型、姓名和账户归属。

不覆写历史已确认方案、客户、正式资源或已生成文件。历史不合规姓名在重新申请时会提示修改准备数据，不能静默修改已确认姓名。保持准备数据与预期结果的两次明确确认。
