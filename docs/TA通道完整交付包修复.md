不能把七文件固定套给所有通道。部署默认配置在 `Backend/config/delivery-profiles.json`；工作空间内可通过 API 保存独立通道配置，优先于部署默认配置。分支代码没有按某个基金、持有期、日期或对比数量生成专用结果。

`GET /api/exchange/channels/:channelId/delivery-profile` 返回生效配置。
`PUT /api/exchange/channels/:channelId/delivery-profile` 提交 `{"profile": {...}}` 保存完整配置；要求会话、同源和 JSON，请先读取现有配置再修改。
