# 语音输入接入（2026-10-11）

用户授权实现并直接合入5199。功能分支 `codex/voice-dictation` 从统一平台 `ef172dd6` 建立，功能提交 `a225dca1`，组合最新空白对话引导 `447634e9` 后形成 `e4d4a252`，已快进合入本机 `codex/platform-integration`。前端5199继续热更新，API3106及数据库不变；没有push或PR。

## 已实现

- 复用已安装的 assistant-ui `WebSpeechDictationAdapter`，中文 `zh-CN`、连续识别与临时文字预览，无新增依赖。
- 输入框右下角增加麦克风；听写时显示计时、取消、完成。输入暂时只读，发送入口暂时隐藏，Enter不会提交；完成按钮仍可用Enter操作，Escape取消后回到输入框。
- 只有完整识别文字会追加到原输入之后，保留编辑和手动发送。取消不写入草稿。识别失败可以明确选择使用已完整识别的部分，不保留不稳定的临时结果。
- 切换Case、退出页面、切换浏览器标签、离开对话或进入只读状态时取消会话，并忽略迟到结果。准备数据和预期结果的点击确认不受影响。
- 启动15秒未成功会取消；单次最多120秒后结束识别。合并后超过4000字明确提示，不静默截断。
- 不支持语音识别或非安全上下文时点击会显示替代入口提示；权限、网络和空识别失败如实显示。浏览器识别服务不可用时不会显示虚假成功。

## 接入边界

当前是浏览器听写，不是实时双向语音通话，没有新增后端音频转写服务。浏览器可把音频发到其识别服务；不保证离线或各网络均可用。Safari、Chrome、Edge及嵌入式WebView的实际可用性取决于浏览器实现、系统权限和网络，存在API并不代表服务可用。

`DictationSession` 消费 assistant-ui 的 `DictationAdapter.Session` 约定，暂存结果以支持取消及现有受控草稿。以后可替换 `createSession` 接入专用转写服务，不需要更换聊天UI。当前适配器不提供详细的错误码，因此界面提示同时检查权限和网络。

没有把Sophnet `DeepSeek-V4-Pro-0813` 文本模型接口当作语音识别接口。本轮未调用该模型、未读取其密钥、未录制或上传真实音频；没有验证真实中文语音准确率。客户可在5199点击麦克风试讲并检查回填文字。
