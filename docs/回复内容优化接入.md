# 回复内容优化接入

从统一平台基线92e1f738在独立codex/reply-content-integration工作树整合对比试验中的回复内容改进。保留最新草稿优先、实时销售商候选、一轮后整理方案和原数据/预期双确认规则。

普通讨论按当前工作空间/项目/Case读取只读快照，包含方案、确认、文件证据和实际阶段。历史AI描述不能代替系统记录，草稿不能引导直接确认或生成。短问短答；需要比较时共同条件一次说明、差异对齐，不凭状态名称编造处理机制或拒绝原因。未确认或未执行内容不冒充完成。讨论退回草稿和执行阶段限制保持原有行为；没有新增执行阶段聊天入口。

回复校验拒绝后最多重答一次，SSE reset清掉旧流式文字，防止两个答案拼接。校验仍有范围限制，不能保证完全杜绝模型错误，被拒绝文字可能在流式校验完成前短暂显示。

保留现有Markdown渲染，不接入Streamdown及其依赖；没有增加首页或方案页布局。旧回复不重写，新规则只用于后续调用。
