# 销售商文件格式配置

数据页销售商新增“文件格式”列，编辑同一销售商时可修改交付结构。配置复用 exchange_channels 与 exchange_delivery_profiles 的工作空间/通道一对一关联，结构化 JSON 存储；不创建第二套销售商身份。名称和格式同事务保存，名称单独更新的旧接口保留原格式。

生成器读取这一份关联配置。新销售商根据销售商代码、TA和协议读取默认值并保存；旧销售商未保存配置时使用已有生产默认值。更新只影响后续生成，历史 ZIP 下载仍读取不可变原件。227 在当前工作空间通过真实界面保存本地参考对应配置：AML及空R1、无序号、无索引后缀、销售商/日期目录、字典大小写、汇总999、空发送/接收方、末尾CRLF。

可编辑项为配套文件、序号、OFI/OFX独立后缀、目录、字段名大小写和文件头。协议21禁用22专属AML/R1。字段宽度、顺序和业务字段仍由协议字典与后端校验管理；没有宣称支持任意私有字段重排或非空R1税务申报。005的-DLJJ依据用户纠正；005/926仍缺独立本地参考，不能把227验收套给它们。

界面延续已有数据页材质、字号、颜色和编辑弹窗，只增加一个列和一个表单分组。表单用真实label、fieldset和原生输入校验；文件名示例随配置变化，保存状态、默认格式加载失败重试、取消及焦点恢复沿用现有模式。桌面两列、窄屏一列，390px页面不溢出，底部操作固定可用。设计检查通过，没有新增装饰性指标或业务确认。
