# 业务准入上下文修复

用户在 Case 讨论中回复“你可以推荐吗？帮我生成一版”，原审核只读取近期用户需求，没有读取 AI 上一轮提出的建议和问题，导致正常接续讨论被判为无关。

## 实现

准入上下文保留当前工作空间、项目与 Case 范围校验，加入最初需求及最近六个完整回合的用户和 AI 消息，按时间排序；未完成回合不参与。用户消息最多4000字符、AI消息最多6000字符，已有方案最多16000字符。AI回复仅用于理解指代，不代表已确认事实或执行授权。

通用政策允许承接 Case 的推荐、思路、条件比较、假设和草稿请求，缺少规则或数据由讨论助手继续建议或澄清。允许用户调整测试目标，新 Case 也能请 AI 帮忙梳理需求。明确无关的请求仍拒绝，材料用途不明、无关图片或夹带绕过审核的请求继续澄清。未增加案例关键词白名单。

审核版本改为 business-admission-context-v2，旧拒绝缓存不再复用；上下文变化也改变缓存键。严格输出解析、并发租约、账户隔离、协议校验以及准备数据/预期结果的两次点击确认保留。
