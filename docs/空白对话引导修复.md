# 空白对话引导修复

原因：真实 `/data` 接口在尚未准备数据时返回 `status: NOT_STARTED` 的对象（包含空数组），而欢迎区把任何非空对象都当成已有产物，因此在真实空白 Case 中被隐藏。旧合成夹具返回 null，未覆盖实际接口形态。欢迎区同时缺少机器人图片。

修复：允许未开始的数据状态显示引导，继续排除已有方案、已准备数据、消息、加载、运行、失败、完成或只读状态。复用现有品牌机器人图片，配合“想测试什么业务或规则？”与两行输入说明；用户输入未发送时保留，发送消息后隐藏。没有后端改动。

分支 codex/chat-palette-options，预览5231；已在独立功能树合入最新5199平台基线1d73dbb1，保留此前四外观全页面样式及滚动按钮修复。5199本轮未修改。

验证：54项常规前端测试、构建通过（保留既有大包警告）。浏览器覆盖四外观×桌面/手机/矮窗口12组合，图片加载、未发送草稿、窄屏无横向溢出；合成新建Case、发送隐藏、已有历史不显示均通过。滚动按钮三尺寸回归通过。截图和日志：.context/empty-guidance；可重跑脚本 Frontend/scripts/empty-guidance.browser.mjs，PLAYWRIGHT_MODULE指定本机Playwright模块。

按本地senior-staff-engineer skill自审：无Blockers、Important或Nits；核对真实接口契约、显示状态门槛及合成夹具。未调用真实模型、写业务数据、push或创建PR。浏览器全部使用合成接口，未声称完成真实模型验收。
