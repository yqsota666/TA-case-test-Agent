# 开放式基金销售系统与 TA 数据交换 Demo

本项目模拟蚂蚁销售系统与广发基金 TA 之间绕过中央数据交换平台后的直接文件交换。第一阶段实现 01、02、03、04、05、07 文件，业务场景为个人客户开户和普通开放式基金申购。

## 系统组成

| 组件 | 实现 |
|---|---|
| 销售系统 | 独立 Node.js 服务与 MySQL 8 数据库 |
| TA 系统 | 独立 Node.js 服务与 Oracle Database Free 数据库 |
| 文件交换 | 独立 SFTP 服务，按场景、日期和批次隔离 |
| 协议模块 | GB18030、定长记录、CRLF、OFI/OFJ 索引、文件头尾和记录数校验 |
| 操作台 | React 单页应用，分别提供客户、销售系统、TA、文件和场景控制视图 |

应用层使用 Node.js 是为了让实习 Demo 易于运行和阅读；TA 的业务数据实际写入独立 Oracle 数据库。生产级 TA 还需要 RAC/Data Guard、批量调度、灾备、权限隔离、监控和更完整的业务规则。

## 已实现流程

1. TA 配置基金并生成 07 与 OFJ 索引。
2. 销售系统接收 07，更新基金、净值和申购限额。
3. 为多个个人客户创建 001 开户申请。
4. T 日截止后封批：账户申请合并为一个 01，交易申请合并为一个 03，同一个 OFI 索引声明当日实际存在的文件。
5. TA 可在 T 日接收申请文件，但只允许在下一交易日 T+1 清算。
6. T+1 清算完成后，TA 将全部 02、04 和清算后全量 05 放入同一个 OFJ 确认包。
7. 销售系统分别解析 02、04、05，并通过申请单编号更新开户、订单、资金和持仓状态。
8. 客户提交订单时仍逐笔冻结模拟银行卡资金；物理交换文件只在 T 日封批时生成。
9. 对账不一致时，可人工点击“以 TA 为准”同步。

## 启动

机器需要 Docker Desktop，并为 Oracle 容器预留足够内存和磁盘。Oracle Free 本身限制为 2 CPU、2 GB 数据库内存和 12 GB 用户数据。

```bash
cd /Users/apple/Documents/ChatGPT/gf/fund-sales-demo
docker compose up --build
```

首次启动 Oracle 会比其他容器慢。所有服务健康后打开：

- 操作台：<http://localhost:5173>
- 销售服务健康检查：<http://localhost:8081/api/health>
- TA 服务健康检查：<http://localhost:8082/api/health>
- SFTP：`localhost:2222`，用户名和密码均为 `exchange`

停止服务：

```bash
docker compose down
```

连数据库卷一起重新初始化：

```bash
docker compose down -v
docker compose up --build
```

## 推荐演示顺序

在“全链路操作台”按编号执行：

1. TA 发送 07，销售接收 07。
2. 在“客户与申购”添加客户并点击模拟开户。
3. 销售封批并发送 T 日 01/03，TA 接收对应申请文件。
4. 业务日推进到下一交易日 T+1，TA 才能处理 T 日申请。
5. TA 一次生成 T+1 的 02/04/05 确认包，销售接收并更新业务状态。
6. 为已开户客户连续提交多笔申购，再重复一次 T 日封批和 T+1 确认流程。

## 测试

协议模块不依赖数据库，可单独运行：

```bash
npm install
npm test
npm run build:web
npm run test:smoke
```

前两项可离线执行；`test:smoke` 需要容器已健康，会重置一个独立场景并实际验证 07、T 日 01/03 封批、T+1 处理、02/04/05 合并确认包，以及含三条 022 的 03/04 全链路。协议测试覆盖 GB18030 中文字节宽度、八位净值的小数点移除与恢复、07 文件往返、索引和记录数错误拒绝。

## 关键边界

- 文件级错误（头尾、字段、记录数、编码、索引缺失）整批拒绝。
- 可解析的业务错误逐条返回失败确认，不影响同文件其他记录。
- 同一个物理包可包含多个文件类型；重复导入按场景、传输目录和文件类型联合幂等控制。
- T 日申请不可在当日清算；`TransactionDate` 保持 T，确认文件名、文件头和 `TransactionCfmDate` 使用 T+1。
- 申购费率保存在 TA；第一阶段不实现 C5，04 返回最终费用和份额。
- 只支持个人居民身份证和普通非货币基金。
- “重置演示”创建新的场景编号并清空当前业务数据；历史 SFTP 文件按场景保留。
